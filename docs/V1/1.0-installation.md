## 휴대폰에서 업데이트

1. GitHub에 로그인한 상태에서 위 고정 서명 artifact ZIP을 다운로드하고 휴대폰 파일 앱에서 압축을 푼다.
2. `app-debug.apk`를 열어 기존 Health App을 업데이트한다. 기존 앱을 삭제하면 로컬 상태·grant를 잃을 수 있으므로 업데이트를 사용한다.
3. 앱에서 Health Connect 가용성·권한과 현재 Drive/로컬 SAF 구성을 확인한다. 수동 Drive는 별도 동의·인증 후 **업로드 계속**으로 실행한다.
4. 자동 Drive를 사용하려면 지원되는 기기의 별도 background 읽기 권한과 **자동 동기화 켜기** 동의를 완료한다. 권한 부여만으로 자동 실행을 켜지 않는다. 자동 심박은 미입증 범위로 차단하며 정확한 실행 시각을 보장하지 않는다.

같은 계정에서 항목을 변경하거나 자동 동기화를 껐다 켜도 기존 파일 추적·불확실한 쓰기·소비한 재시도 예산을 보존한다. 과거 데이터는 현재 읽기 권한이 아니다. 로컬 상태 초기화는 원격 파일 삭제나 시스템 권한 철회가 아니다. 현재 SAF는 검증된 전경 local tree만 지원한다.
